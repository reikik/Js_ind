## Описание проекта

**Advanced To-Do List** — это интерактивное веб-приложение для планирования и управления повседневными задачами. Проект разработан на чистом JavaScript (**Vanilla JS**) с использованием современного синтаксиса ES6+ и разделением логики на независимые модули.

### Цель проекта
Развить и продемонстрировать на практике навыки работы с объектной моделью документа (DOM), обработки пользовательских событий, валидации входных данных, фильтрации и сортировки массивов объектов, а также организации поддерживаемой архитектуры кода при помощи JS-модулей.

## 📂 Структура проекта

Приложение имеет четкую древовидную структуру. Все исходные файлы JavaScript вынесены в отдельную директорию `js` для разделения логики и разметки.

```text
todo-app/
│
├── index.html          # Главная HTML-разметка и каркас приложения
├── style.css           # Таблица стилей (адаптивная верстка, темы приоритетов)
├── README.md           # Сопроводительная документация проекта
│
└── js/                 # Директория с JavaScript-модулями
    ├── app.js          # Центральный контроллер (Точка входа, State, Event Listeners)
    ├── storage.js      # Модуль данных (LocalStorage, API Mock, асинхронные операции)
    └── render.js       # Модуль отображения (Интерфейс, генерация DOM, обработка ошибок)
```    

Приложение спроектировано в соответствии с модульным подходом ES6. Код разделен на слабо связанные компоненты, где каждый модуль отвечает исключительно за свою бизнес-логику (принцип Единственной ответственности / Single Responsibility).

1. **`index.html` (Структура и разметка):**
   * Содержит семантическую разметку формы ввода, блока фильтров/сортировки и контейнера для списка задач.
   * Основной скрипт подключается с атрибутом `type="module"`, что изолирует область видимости каждого файла и позволяет использовать синтаксис `import/export`.

2. **`js/app.js` (Контроллер приложения):**
   * Является "мозгом" приложения и главным связующим звеном. 
   * Хранит в себе глобальное состояние — массив объектов `tasks`.
   * Инициализирует приложение после полной загрузки DOM (`DOMContentLoaded`).
   * Навешивает глобальные обработчики событий (включая **делегирование событий** для динамически создаваемых элементов списка задач).
   * Содержит функцию `updateApp()`, которая координирует последовательную фильтрацию, поиск и сортировку данных перед отправкой их на отрисовку.

3. **`js/render.js` (Управление DOM и интерфейсом):**
   * Отвечает исключительно за визуальное отображение и работу с интерфейсом. Данный модуль не хранит состояние данных.
   * Динамически генерирует HTML-код элементов списка (`<li>`) с помощью метода `document.createElement`.
   * Содержит функцию `escapeHTML()`, которая преобразует спецсимволы (`<`, `>`, `&`), защищая приложение от **XSS-атак** (внедрения вредоносного JS-кода через инпуты).
   * Управляет отображением и скрытием модальных окон и блоков валидации с помощью переключения CSS-класса `.hidden`.

4. **`js/storage.js` (Слой работы с данными / Data Layer):**
   * Отвечает за долговременное хранение: сериализует массив задач в формат JSON-строки для записи в `LocalStorage` и производит обратное чтение при старте.
   * Реализует асинхронную функцию `fetchMockTasks()`. Используя `Promise` и `setTimeout`, она имитирует реальный сетевой запрос к серверу (с задержкой в 500мс) для загрузки демонстрационных данных, если локальное хранилище пользователя полностью пусто.

### Основные функции приложения
* **Динамическое управление DOM:** Добавление, переключение статуса выполнения и удаление задач без перезагрузки страницы.
* **Категоризация по приоритетам:** Каждой задаче можно присвоить уровень важности (`High`, `Medium`, `Low`), который визуально отображается на интерфейсе с помощью цветовых индикаторов.
* **Комплексная работа с данными (массивы объектов):**
  * **Поиск:** Сквозной интерактивный поиск задач по вхождению текста в реальном времени.
  * **Фильтрация:** Разделение списка на вкладки «Все», «Текущие» и «Завершенные».
  * **Сортировка:** Возможность упорядочивания задач по дате создания (сначала новые/старые) и по весу приоритета.
* **Строгая валидация:** Защита от ввода пустых строк или слишком коротких названий (менее 3 символов) с выводом понятных пользователю сообщений об ошибках прямо в интерфейсе.
* **Интерактивный UX (User Experience):** Кастомное модальное окно для подтверждения деструктивных действий (удаления задачи).
* **Работа с хранилищем (Асинхронность и Storage):** * Автоматическое сохранение и загрузка списка задач из `LocalStorage` браузера (данные не пропадают после обновления страницы).
  * Имитация работы с внешним API с использованием `async/await` и `Promise` для загрузки демонстрационных данных при первом старте.


## Инструкции по установке и запуску проекта

### Зависимости
Проект является полностью клиентским (Frontend) и использует стандартные веб-технологии: **HTML5, CSS3, Vanilla JS (ES6+)**. 
* Специальные системные зависимости, пакетные менеджеры (`npm`) или сборщики (`Webpack`, `Vite`) **не требуются**.
* Для корректной работы JavaScript-модулей (`import/export`) браузер требует, чтобы файлы открывались через протокол `http://` или `https://`, а не напрямую через локальный файл (`file://`).

### Основные шаги для запуска приложения

#### С использованием Visual Studio Code
1. Установите редактор кода **Visual Studio Code**.
2. Перейдите во вкладку расширений (`Ctrl+Shift+X`) и найдите расширение **Live Server** (автор: *Ritwick Dey*), нажмите **Install**.
3. Откройте папку проекта (`todo-app`) в VS Code.
4. Откройте файл `index.html`.
5. Кликните по кнопке **Go Live** в правом нижнем углу окна редактора (или нажмите правой кнопкой мыши по `index.html` в проводнике и выберите *Open with Live Server*).
6. Приложение откроется в вашем браузере.
